# LiveXP

QQ Xposed 模块:在聊天界面检测实况图片,添加完整的实况图片提示,并实现 像相册那样的 查看实况图片动态画面 的功能。

> **⚠️ 未完成作品 / WIP** —— 本项目仍在开发中,功能不稳定,判定规则需要真机数据持续校准,请勿在生产环境依赖。
>
> **📌 版本说明** —— 当前仓库仅保留**第一版**文件,作为项目起点存档。后续开发仍在继续,等功能完善、以及本仓库 star 数量增长后会再推送迭代版本。想看更成熟的实现,请持续关注。

## 现状

- ✅ QQ 设置页模块入口
- ✅ 实况图片检测和角标提示
- ✅ 简陋的实况图片播放
- 🚧 性能优化,交互细节等未完善

## 已验证的环境

- QQ 9.3.70(NT 内核,tinker 热更)+ LSPosed 2.2.1
- Android 16 / arm64

## 用法

LSPosed 里启用模块并勾选 QQ 作用域,重启 QQ:

- QQ 设置页出现「LiveXP 模块」入口,点击查看运行日志
- 聊天里的实况图片气泡会(在判定命中后)显示「实况」角标
